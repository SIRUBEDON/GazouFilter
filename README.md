# GazouFilter

ブラウザで使える画像フィルター＆加工ツール。インストール不要で、`index.html` をブラウザで開くだけで使えます。処理はすべてブラウザ内で完結し、画像がサーバーに送信されることはありません。

## できること

- フィルター調整：明るさ・コントラスト・彩度・色相・ぼかし・シャープネスなど
- プリセットフィルター：セピア・グレースケール・反転ほか
- 加工：リサイズ・回転・圧縮
- 複数画像の一括処理と、ZIP 形式での一括ダウンロード
- 画像の並び替え（ドラッグ＆ドロップ）

## 使い方

1. このリポジトリの `index.html` をダウンロードしてブラウザで開く（または GitHub Pages 等に配置する）
2. 画像をドラッグ＆ドロップで読み込む
3. フィルターやプリセットを選んで調整し、書き出す

## 依存ライブラリ（CDN）

- Tailwind CSS
- JSZip 3.10.1
- SortableJS 1.15.0
